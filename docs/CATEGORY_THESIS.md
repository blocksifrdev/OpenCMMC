# The category: Proof-Driven Compliance

**Category promise:** Don't just check whether control artifacts exist. Test whether each bounded technical claim is actually supported by evidence, produce a falsifying modeled counterexample where possible, and show the exact remaining evidence gap.

**Who it's for:** Developers, cloud security teams, GRC analysts, independent assessors, MSPs, and resource-limited organizations that need transparent, portable, zero-subscription compliance readiness tooling.

**Free-forever commitment:** Open-source local scanning, finite-model proof evaluation, user-defined controls and ordinary JSON/HTML evidence exports remain available without a paid hosted account or API key. Apache-2.0 licensed. Framework content is subject to licensing, completeness, and currency constraints.

**Entry wedge:** A five-minute demonstration: a repository contains CODEOWNERS, branch protection and CI; a checklist appears favorable, but a technically scoped obligation about bypass paths remains unproven. Theorem Intelligence returns a witness assignment and a bounded minimum evidence plan. Neither a hypothetical witness nor proof within a narrow model is a confirmed production defect.

**Category measurement:** Time to reviewed evidence; percent of mapped obligations with model-supported, model-counterexample or unknown status; independently verified counterexample rate; false assurance rate; average evidence acquisition cost; number of obligations invalidated by a source or model change; independently replicated test outcomes.

**Revenue boundary:** Compliance readiness and bounded proof are free. BlockSiFr Control remains a separately purchased option for consequential-action authorization, runtime enforcement, connected multi-tenant enterprise operations, and signed execution receipts. FreeCompliance must never require BlockSiFr Control.

**Defensibility:** The open-source standard can become a portable evidence and obligation contract, while proprietary execution control and consequence response remain distinct. Adoption and meaningful proof-quality benchmarks, not slogans, determine market leadership.
