# Prepare a private OpenCMMC service request

OpenCMMC readiness remains free and offline. After creating an assessment, you may choose **Prepare a private request** for CortexTrace, BlockSiFr Control or BLAKE.

1. Choose a service card and read its local setup explanation.
2. Check the explicit confirmation box. Nothing is generated until you confirm.
3. Download a minimal local JSON planning file. It contains only the service choice, predefined request purpose, a random reference and preparation timestamp.
4. If you want provider onboarding, choose to open the separate information page and arrange authorization under your organization's rules.

**No information is transmitted by the OpenCMMC request workflow.** No assessment, scope, control ID, evidence, reviewer name, filepath, hash, repository, credentials, session URL or CUI is included. The file is an offline request plan, not a purchase order, activated coding session, runtime policy, security scan or execution receipt.

The request has status PREPARED_LOCAL_ONLY. A live commercial integration still requires separate authentication, authorization, exact-scope consent and provider validation.
