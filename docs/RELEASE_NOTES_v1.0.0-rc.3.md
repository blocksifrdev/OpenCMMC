# OpenCMMC v1.0.0-rc.3 | Optional Services and Release Integrity

**Release type:** Public release candidate; not v1.0 general availability, official CMMC certification or a verified government scoring/submission system.

## Added
- Optional, clearly labeled next-step cards in the local browser **after an assessment is created**:
  - CortexTrace for AI coding-session governance and change-impact evidence.
  - BlockSiFr Control for runtime authority, step-up and execution receipts.
  - BLAKE for deeper consequence-focused vulnerability discovery.
- Each link opens a publicly available BlockSiFr information page only when a user clicks it. **No scope, file, report, evidence, tokens, credentials or CUI are uploaded or attached to the link.** The link itself does not activate paid services.
- Automated checks reject retired-brand text in active tracked source, and validate package names, contents, manifest and checksums.
- All local CMMC readiness functions, offline behavior, and JSON report export remain free and unaffected.

## Delivery conditions
The packages for Windows ARM64, Windows x64, Linux ARM64 and Linux x64 are published **only after** native smoke tests and checksums pass. SHA-256 and SPDX are not publisher code-signing or government approval.
