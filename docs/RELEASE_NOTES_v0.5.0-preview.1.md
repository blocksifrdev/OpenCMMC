# FreeCompliance v0.5.0 Preview 1

**Public prerelease: portable downloads for Veterans Day early access.**

Download the package matching your device below. This is the **CLI workbench**; a visual browser UI and a one-click MSI/EXE installer are **not yet shipped**. The binary requires no Go compiler, account, subscription, or mandatory cloud connection.

| Device | Archive |
| --- | --- |
| Windows x64 | `freecompliance-v0.5.0-preview.1-windows-amd64.zip` |
| Windows ARM64 | `freecompliance-v0.5.0-preview.1-windows-arm64.zip` |
| Linux x64 | `freecompliance-v0.5.0-preview.1-linux-amd64.tar.gz` |
| Linux ARM64 | `freecompliance-v0.5.0-preview.1-linux-arm64.tar.gz` |

Each package includes the executable, an offline CMMC demonstration launcher, local-use guidance, and CMMC air-gap instructions. The demonstration uses a synthetic initial workspace. **Do not use real CUI in an unapproved environment.**

**Integrity:** Download SHA256SUMS and verify the package hash. A matching hash does not authenticate the publisher. This preview has no independent, pretrusted offline release signature. Restricted environments must follow their own code review, trusted signing, security authorization and media-transfer controls.

**Scope:** Offline CMMC evidence workspaces, objective-level reviewer workflow, evidence integrity/freshness checks, and experimental bounded theorem evaluation. Independently validated full NIST SP 800-171A objective coverage, SPRS scoring, CMMC certification, government submission, and government endorsement are not included.

Formal Veterans Day initiative launch: November 11, 2026. Public access is available before and after.
